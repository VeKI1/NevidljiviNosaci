# MIKERENJE — Nevidljivi nosači za tablice

## Struktura
- `index.html` — sajt
- `support.js` — runtime (ne brisati)
- `assets/logo.png` — logo
- `assets/hero.png` — glavna slika na vrhu stranice. **Zameni ovaj fajl svojom slikom** (isto ime), format 4:5 uspravno.

## Objavljivanje na GitHub Pages
1. Napravi novi repozitorijum i ubaci sve fajlove iz ovog foldera u koren.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
3. Sajt je na `https://<korisnik>.github.io/<repo>/` za minut-dva.

## Napomene
- Forma za porudžbinu trenutno samo prikazuje potvrdu. Za stvarne porudžbine poveži je sa servisom (Formspree, Google Forms, email).
- Meni (Kako radi, Cene, Pitanja, Poruči) vodi na sekcije iste stranice.
